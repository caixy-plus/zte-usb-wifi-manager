# U25S 接入设备概览验证

日期：2026-08-01

## 结论

LuCI 接入设备页现可从 Wi-Fi 快照展示 2.4GHz、5GHz 和总客户端数。总数只有在
两个分频段计数均为可信整数时才计算；任一计数未知时总数保持未知，避免把未认证
空响应误报为零台设备。

## 隐私与认证边界

当前固件 `service.js` 确认客户端明细来自 `station_list`，元素可能包含 MAC、IP、
主机名、SSID 索引和上下行速率。当前凭据未通过设备认证，因此本批次不请求该数组，
不把任何客户端标识写入状态快照、事件日志、fixture 或文档。

只有取得有效认证 fixture、验证数组缺失字段和异常响应、确认状态文件与 rpcd ACL
权限后，才会增加客户端明细。当前页面明确显示“等待有效认证 fixture 校准”。

## 自动化覆盖

- 两个分频段均有整数计数时计算总数。
- 任一分频段未知时总数显示未知。
- 客户端面板不出现 MAC 或测试网段 IP 文本。
