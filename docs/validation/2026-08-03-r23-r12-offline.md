# r23/r12 离线开发验证

## 结论

backend r23 / LuCI r12 已完成代码开发与本机离线验证。按交付顺序要求，本记录
**不包含**官方 OpenWrt SDK 构建、QEMU 安装或 Cudy/U30 Pro 写操作；这些工作统一
留到最后的构建与真机调试验收步骤，不能用历史版本证据代替。

## 本轮完成内容

- U30 Pro `power_supply_mode` 智能充电：阈值设置、滞回决策、失败冷却、单次写入、
  强制安全读回，以及 LuCI 配置入口。
- 从目标设备 WebUI 静态源码冻结 APN、连接模式、2.4 GHz Wi-Fi、流量计划、流量
  清零、短信发送/删除/已读、重启和关机契约。
- 所有设备 POST 均禁止在结果不明确时自动重试；读回只使用有界 GET。
- APN 与 Wi-Fi 密码不作为读回字段；短信、号码、密码不进入事件日志和 RPC 响应；
  短信编码长度严格限制为 WebUI 的 GSM7 765 / Unicode 335 个编码单位。
- APN 不再暴露静态源码无法兑现的 PDP 类型修改；连接模式和流量套餐会同时校验请求
  固定写入的漫游、单位与自动清零副作用。
- 短信发送/删除使用写前状态基线和命令状态变化进行关联；删除还要求消息写前存在、
  写后消失。重启/关机要求写前在线和可配置的最短离线窗口。
- daemon 在执行边界再次校验完整 payload，拒绝篡改字段、缺失确认及不匹配的动作类型。
- 目标 MU3351 配置明确为 `WIFI_HAS_5G=false`，因此 5 GHz 设置不进入实现范围。
- 写 capability 和各 UCI 写开关继续默认关闭；“已实现”状态不能绕过执行门控。
