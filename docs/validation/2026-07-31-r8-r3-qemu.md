# r8/r3 校准诊断与构建验证（2026-07-31）

## 目的

backend r7 已为 SIM 与 USB 供电 `probe` 补充固定、非敏感、可机器读取的失败码。
主路由器的后续只读证据又证明两个兼容性问题：

1. 匿名 U25S 状态响应会留下关键蜂窝字段为空，SIM 写入校准不能复用只读层的
   “已有任意字段即可”判定，必须先完成真实登录。
2. 官方 OpenWrt 的 `cudy,tr3000-v1-ubootmod` 没有
   `/sys/class/gpio/modem_power/value`；USB VBUS 由 xHCI 消费
   `regulator-fixed` 的 `usb-vbus`。

backend r8 强制 SIM 校准先登录，并增加官方 OpenWrt 的 xHCI bind/unbind
硬件 profile。该 profile 同时检查控制器绑定状态和 `usb-vbus` regulator 状态，
不会把普通总线重置误判为真实断电。

## 诊断契约

- SIM probe 在读取 readiness 字段前强制登录，并区分凭据不可用、认证失败、
  设备读取失败、响应无效、字段缺失、卡槽无效、modem 未连接、网络未注册和
  PPP 未就绪。
- USB power probe 区分板型文件、板型支持、固定控制节点、供电读回、恢复服务和
  设备可达性错误。
- 失败仍返回非零退出码，JSON 只包含固定 `code`，不含密码、Cookie、运营商名称或
  设备标识。
