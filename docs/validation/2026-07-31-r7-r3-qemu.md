# r7/r3 校准诊断与构建验证（2026-07-31）

## 目的

主路由器上的只读预检证明 SIM 与 USB 供电 `probe` 失败时只有退出码，没有安全的
失败原因。backend r7 为两个校准工具补充固定、非敏感、可机器读取的失败码；不会
放开生产写能力，也不会在 `probe` 中执行切卡或 USB 断电。

## 诊断契约

- SIM probe 区分凭据不可用、设备读取失败、响应无效、字段缺失、卡槽无效、
  modem 未连接、网络未注册和 PPP 未就绪。
- USB power probe 区分板型文件、板型支持、固定控制节点、供电读回、恢复服务和
  设备可达性错误。
- 失败仍返回非零退出码，JSON 只包含固定 `code`，不含密码、Cookie、运营商名称或
  设备标识。

## 当前证据

- `test_sim_calibration` 覆盖成功结果和全部新增失败码。
- `test_power_calibration` 覆盖成功结果以及关键失败码。
- GitHub SDK 构建、QEMU 升级与实机重新部署结果将在对应运行完成后补入本文。
