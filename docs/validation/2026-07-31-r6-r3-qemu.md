## 验证项

- 官方签名软件源成功解析 `coreutils-stat`、`curl`、`ip-tiny` 等依赖。
- manager 与 recovery-coordinator 两个 procd 实例可运行；rpcd 对象存在，
  `status` 和 `capabilities` 均返回可解析 JSON。
- LuCI 安装包内包含“设备登录”、`credential_status`、`set_credentials` 以及对应
  ACL；凭据入口为只写，不在响应中回显密码。
- 默认 `write_enabled=0`；无凭据执行 `zte-u25s-sim-calibrate probe` 安全失败，
  且不创建恢复状态或锁。
- 创建持久 `/etc/zte-usb-wifi-manager/sim-calibration.lock` 后，启动脚本在两套
  固件中都注册零个 procd 实例；清除锁后两个实例正常恢复。
- 在运行中的 backend r5 / LuCI r3 上安装 backend r6，APK 和 IPK 都完成原位升级；
  UCI 配置保留，r6 校准工具存在，rpcd/ubus 恢复。
- 正常状态下卸载成功，backend、rpcd、校准工具和 LuCI 页面均被移除。

OpenWrt 的 rc.common 在 `start_service` 拒绝注册实例时仍可能让
`/etc/init.d/... start` 返回零，因此门禁验收以 `ubus call service list` 中实际
实例数为准，而不是以 rc.common 的命令退出码为准。
