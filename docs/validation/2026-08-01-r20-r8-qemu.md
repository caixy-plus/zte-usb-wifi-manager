# r20/r8 隔离 QEMU 安装验证

日期：2026-08-01

## 输入与隔离

- GitHub Actions：
  [30685314327](https://github.com/caixy-plus/zte-usb-wifi-manager/actions/runs/30685314327)
- 源码提交：`bf537b458ead1ddb83422d0097f6b79a8f538eb4`
- backend：`0.1.0_rc1-r20`
- LuCI：`0.1.0_rc1-r8`
- artifact 的 manifest 与四个包先通过 `SHA256SUMS`。

两套测试均从官方 x86/64 ext4 combined 基础镜像创建全新 qcow2 overlay。QEMU
使用用户态 NAT，不桥接物理网卡；虚拟机内禁止访问私有网段并关闭 IPv6。全过程
未访问主路由器或真实 U25S。

为了验证 rpcd exec/ubus 对布尔值的实际传递，两套隔离环境都只在测试期间把 Wi-Fi
capability 与对应 UCI 开关临时改为 1，提交 `set_wifi enabled=false` 到本地运行时
队列；虚拟机路由禁止访问 U25S 网段，daemon 对尚无厂商执行器的动作返回
`unsupported`。测试随后立即恢复 capability 与 UCI 开关为 0，并再次读取确认。
这不是设备写入，也没有开放发布包中的生产能力。

25.12.5 回报 backend 安装体积 223 KiB、LuCI 33 KiB，合计约 256 KiB，不含固件
原本已有依赖。24.10.7 的 `opkg` 未提供可直接比较的 `Installed-Size`。

24.10.7 卸载时 init 脚本输出一次已经不存在的 procd service delete 提示；随后
确认包、ubus 对象、daemon、rpcd、LuCI 页面和运行时目录均已移除。两套 QEMU
进程在验证后均已退出。

## 边界

QEMU 证明包格式、安装生命周期、ubus 传参、OpenWrt ash 兼容性、语义请求边界和
默认安全门控；不能证明语义值到真实 U25S goform 的映射、写入后读回、真实认证、
硬件副作用或 72 小时稳定性。本次没有升级主路由器。
