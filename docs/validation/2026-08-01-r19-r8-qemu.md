# r19/r8 隔离 QEMU 安装验证

日期：2026-08-01

## 输入与隔离

- GitHub Actions：
  [30683284224](https://github.com/caixy-plus/zte-usb-wifi-manager/actions/runs/30683284224)
- 源码提交：`c68e1e1d9edea4d590247e2c7778d0c9cc270b42`
- backend：`0.1.0_rc1-r19`
- LuCI：`0.1.0_rc1-r8`
- artifact 的 manifest 与四个包先通过 `SHA256SUMS`。

两套测试均从官方 x86/64 ext4 combined 基础镜像创建全新 qcow2 overlay。QEMU
使用用户态 NAT，不桥接物理网卡；虚拟机内禁止访问 `10/8`、`100.64/10`、
`169.254/16`、`172.16/12`、`192.168/16`，并关闭 IPv6。直连的
`192.168.1.0/24` 仅用于 QEMU 内部管理链路。全过程未访问主路由器或真实 U25S。

24.10.7 卸载时 init 脚本输出一次已经不存在的 procd service delete 提示，随后
确认包、ubus 对象、daemon、rpcd 脚本、LuCI 页面和凭据文件均已移除，因此生命
周期仍为 PASS。两套 QEMU 进程在验证后均已退出。

## 边界

QEMU 证明包格式、依赖、安装脚本、服务、能力矩阵、凭据本地生命周期、安全门控与
卸载生命周期；不能证明有效凭据下的真实私有数据、任何真实 U25S 写操作、USB
硬件行为或 72 小时运行稳定性。本次没有升级主路由器。
