# r21/r10 隔离 QEMU 安装验证

验证日期：2026-08-01

| 环境 | 结果 |
|---|---|
| OpenWrt 25.12.5 APK | PASS |
| OpenWrt 24.10.7 IPK | PASS |

两台 x86_64 虚拟机均使用 QEMU user-mode NAT，没有桥接宿主机局域网；客户机启动后
显式安装 `prohibit 192.168.0.0/16` 路由并关闭 IPv6。验证过程没有连接 Cudy 路由器
或 U25S。

每个系统都从未安装插件的基础镜像创建新 qcow2 overlay，并依次通过：

- 下载并安装 backend r21 / LuCI r10。
- 校验包版本、procd/rpcd 启动及 `zte_usb_wifi` ubus 对象。
- 校验 cellular、Wi-Fi、traffic、SMS、device reboot、device shutdown 六类生产
  capability 全部为 `false`。
- 对 `device_action` 提交重启与关机确认请求，两项均由服务端返回 `unsupported`。
- 校验 LuCI 包包含 `device_action` RPC 和两项独立确认控件。
- 校验全局写门及六项功能 UCI 开关全部保持 `0`。
- 卸载两个包后，LuCI 资源、rpcd 脚本和运行状态目录均清理完成。
- 最终正常关机，验证结束后没有遗留 QEMU 进程或临时 HTTP 服务。

串口验证标记 `NETWORK`、`DOWNLOAD`、`INSTALL`、`VERSION`、`RPCD`、`GATES`、
`DEVICELOCK`、`LUCI`、`UCI`、`REMOVE`、`CLEANUP` 在两个系统中均为 `OK`。

QEMU 只能证明包生命周期、OpenWrt 集成、拒绝路径与默认安全门控；真实厂商写映射、
设备断线与恢复读回仍必须等待备用 U25S 实机校准。
