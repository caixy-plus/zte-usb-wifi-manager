# r30/r12 默认出口门禁与最终安全验证

日期：2026-08-03

## 结论

backend r30 / LuCI r12 已通过本地完整回归、GitHub Actions 上的 OpenWrt 25.12.5
与 24.10.7 官方 SDK 构建、两套隔离 QEMU 中从 r29 原位升级，以及 Cudy TR3000 v1
+ U30 Pro 的最终只读部署验证。

r30 把“U30 不能是默认互联网出口”从人工操作要求提升为程序强制门禁：IPv4 或 IPv6
默认路由使用目标网卡时，`probe` 和 `execute` 都会拒绝；路由表无法检查时同样
fail-closed。`execute` 在首次设备 POST 前还会二次检查并处理路由变化，避免检查与
写入之间的竞态。

本次没有执行任何 `power_supply_mode` 写入。U30 仍是 Cudy 的默认互联网出口，真机
`probe` 按设计返回 `device_is_default_route`。生产 capability、全局写开关、供电模式
写开关和智能充电开关均保持关闭。
