- GitHub Actions：
  [30682417836](https://github.com/caixy-plus/zte-usb-wifi-manager/actions/runs/30682417836)

使用用户态 NAT，不桥接物理网卡；虚拟机内禁止访问 `10/8`、`100.64/10`、

`192.168.1.0/24` 仅用于 QEMU 内部管理链路。全过程未访问主路由器或真实 U25S。

QEMU 证明包格式、依赖、安装脚本、服务、能力矩阵、安全门控与卸载生命周期；不能
证明需要有效凭据的真实私有数据、任何真实 U25S 写操作、USB 硬件行为或 72 小时
运行稳定性。本次没有升级主路由器。
