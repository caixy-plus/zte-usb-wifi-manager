# U25S 设备详情只读验证

日期：2026-08-01

## 结论

当前 U25S 原厂设备信息页使用市场名称、硬件版本、软件版本和 WebUI 版本；主状态
模型同时使用新版本与当前升级状态。项目已将六个非唯一标识字段加入只读快照，并
在 LuCI 设备页展示。

字段为 `device_market_name`、`hardware_version`、`wa_version`、`web_version`、
`new_version_state` 和 `current_upgrade_state`。空值与缺失值统一规范化为 `null`，
不会伪造版本号或升级进度。

## 证据与隐私边界

- 当前固件 `service.js` 明确读取并映射上述字段。
- 匿名 schema-only 请求确认字段均为字符串类型，但未认证会话下为空。
- 探测只记录字段名、类型和空值状态；没有记录真实版本值或设备标识。
- 同一原厂接口还包含 IMEI 等唯一标识，项目读取白名单明确排除这些字段。

本批次仅展示升级状态，不提供在线检查、下载或刷写操作。

## 自动化覆盖

- Adapter 使用合成版本值验证规范化对象。
- LuCI 验证设备页六个新增字段。
- 模拟器读取 allowlist 与生产字段保持一致。
