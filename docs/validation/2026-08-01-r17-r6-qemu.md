# r17/r6 隔离 QEMU 安装验证

日期：2026-08-01

## 输入与隔离

- GitHub Actions：
  [30681487669](https://github.com/caixy-plus/zte-usb-wifi-manager/actions/runs/30681487669)
- 源码提交：`c8fca36d263c82f2cf83210c3a14f9fc64fca36f`
- backend：`0.1.0_rc1-r17`
- LuCI：`0.1.0_rc1-r6`
- artifact 的 manifest 与四个包先通过 `SHA256SUMS`。

OpenWrt 25.12.5 和 24.10.7 分别使用官方 x86/64 ext4 combined 基础镜像与全新
qcow2 overlay。QEMU 仅使用用户态 NAT，不桥接物理网卡；虚拟机内禁止访问
`10/8`、`100.64/10`、`169.254/16`、`172.16/12`、`192.168/16`，并关闭 IPv6。
其中直连的 `192.168.1.0/24` 只承载 QEMU 内部管理链路。全过程未访问主路由器或
真实 U25S，结束后两个 QEMU 进程均已退出。

- OpenWrt 24.10.7 IPK：PASS

25.12.5 的包管理器回报 backend 安装体积 209 KiB、LuCI 30 KiB，合计约 239 KiB，
不含固件原本已有的依赖。24.10.7 的 `opkg` 没有提供可直接比较的
`Installed-Size`；其包文件清单可正常安装和清除，因此不使用包含共享目录重复
计数的 `du` 数值作为安装体积结论。

24.10.7 卸载时 init 脚本输出一次已经不存在的 procd service delete 提示，`opkg`
仍成功完成；等待 rpcd 刷新后，已确认软件包、ubus 对象、daemon、rpcd 脚本和
LuCI 页面全部消失，生命周期判定为 PASS。

## 边界

QEMU 证明包格式、依赖、安装脚本、procd/rpcd/ubus、权限、默认安全门控和卸载
生命周期。它不能证明需要有效 U25S 凭据的客户端明细、短信列表内容、设备写接口、
USB 硬件行为或 72 小时运行稳定性。本次没有升级主路由器。
